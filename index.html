划词翻译 · 生词本

一款轻量的浏览器插件：选中英文即译，词性、音标、例句、词形一目了然； 一键存入生词本，支持复习、统计与导出，帮你轻松积累词汇。

浏览器扩展 划词翻译 生词本 Anki 导出 主题换色

✨ 主要功能

划词即译选中英文单词，弹出中文释义、音标、词性、词形变化与中英例句。
朗读发音点击喇叭按钮，即可听标准美式发音。
生词本一键存入，支持按难度标记、搜索、排序与随机复习。
学习统计记录今日新增、累计与连续打卡天数，激励坚持。
导出备份一键导出 Anki / CSV / JSON，随时备份与迁移。
主题花边蓝、粉、黄、紫、绿五种主题色，弹窗与页面一键换肤。
生词自动高亮打开网页自动标出已学单词，点击即可查看释义。
每日复习提醒设置时间，到点温柔提醒你复习生词本。

🚀 使用方法

  1. 在 Edge / Chrome 的扩展管理页开启「开发人员模式」；
  2. 点击「加载解压缩的扩展」，选择本项目文件夹；
  3. 打开任意英文网页，选中单词即可查看翻译；
  4. 点击「存入生词本」，积累你的专属词汇库。
