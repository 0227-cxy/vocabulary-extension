# 划词翻译 · 生词本

Chrome / Edge Manifest V3 扩展：网页划词英译中，词性、音标、例句、词形一目了然；一键存入生词本，支持复习、统计与导出，帮你轻松积累词汇。

## 安装（开发者模式）

1. 打开 Edge → `edge://extensions`（Chrome 为 `chrome://extensions`）
2. 开启右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择本项目文件夹

## 功能说明

| 功能 | 说明 |
|------|------|
| 划词翻译 | 选中英文约 0.3s 弹出浮窗；可拖动标题栏、关闭、复制译文、存入生词本 |
| 词性 · 词形 | 单个单词自动补充音标、词性（n./v./adj.）、词形变化（复数、过去式、比较级等） |
| 中英例句 | 单词配 1~2 条中英对照例句 |
| 发音朗读 | 点击 🔊 按钮朗读该单词 |
| 右键菜单 | **翻译并存入生词本**：一次完成翻译 + 保存，并展示浮窗 |
| 翻译引擎 | 默认 MyMemory（免 Key）；设置页可切换有道 / 百度（失败时自动回退 MyMemory） |
| 生词本 | 完整页 `pages/vocab.html`：搜索、排序、随机复习、导入导出 |
| 难度标记 | 生词可标「生疏 / 熟悉 / 掌握」，点击切换、按难度筛选 |
| 数据导出 | 一键导出 **Anki / CSV / JSON**，支持 JSON 导入 |
| 学习统计 | 记录今日新增、累计数量、连续打卡天数 |
| 主题换色 | 蓝 / 粉 / 黄 / 紫 / 绿 五色一键切换，弹窗与页面同步换肤 + 花边 |
| 生词自动高亮 | 打开网页自动标出已学单词，点击即可查看释义 |
| 每日复习提醒 | 设置时间，到点弹系统通知温柔提醒复习生词本 |

## 目录结构

```
manifest.json
background.js        # 后台：翻译、词典、每日提醒
index.html           # GitHub Pages 首页
content/             # 划词浮窗 + 生词高亮
lib/                 # 翻译、词典、存储、主题、统计、小猫
popup/               # 浏览器图标弹窗
options/             # 设置（翻译引擎、主题、提醒、高亮）
pages/vocab.html     # 生词本完整页
styles/shared.css    # 共享主题样式
icons/
```

## 数据存储

生词、设置与学习统计保存在 `chrome.storage.local` 的 `vocabulary`、`settings`、`learningStats` 键中。
